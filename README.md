
# VayoraWeather

A responsive weather dashboard built with HTML, CSS and modular JavaScript.

## Features
- City search using Open-Meteo geocoding
- Live weather conditions and five-day forecast
- Async/await and Fetch API
- Error handling and loading feedback
- Responsive layout and accessible labels
- Modular JavaScript files and hash navigation

## Run locally
Open this folder using VS Code Live Server. ES modules may not work when opening index.html directly as a file.

## Deployment
Upload the project to a GitHub repository and import it into Vercel or Netlify.
Set the project root to the folder containing index.html.
No build command is needed for this plain HTML/CSS/JavaScript project.

## Note
Weather data is provided by Open-Meteo. This demo has no backend or payment features.
